# 🚗 Автосалон Drive Premium

## Описание проекта
Веб-приложение автосалона с полным функционалом: каталог автомобилей, регистрация, авторизация, админ-панель, поиск, фильтрация, пагинация и экспорт в Excel.

## Функционал
- ✅ Регистрация и вход пользователей
- ✅ Разграничение ролей (админ/пользователь)
- ✅ CRUD операции с автомобилями
- ✅ Поиск и фильтрация по цене, бренду, типу двигателя
- ✅ Пагинация (6 авто на странице)
- ✅ Экспорт данных в Excel
- ✅ Личный кабинет пользователя

## Технологии
- Node.js + Express
- PostgreSQL
- bcrypt (хеширование паролей)
- express-session (сессии)
- exceljs (экспорт в Excel)

## Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Создать файл `.env` с настройками БД
4. Запустить сервер: `node server.js`
